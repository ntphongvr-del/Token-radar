Token launch radar — ranks 177 pre-token DeFi protocols by implied token value, from a sealed DefiLlama snapshot (758 protocols, 2026-11-14). Each row carries a concrete farm plan (cost + time per step) and the dashboard runs fully offline.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
